12.010 Project: "Display Tank" Aquarium Visualizer
-----------------------------------------------------------------------------------------------------
OPERATION INSTRUCTIONS

To run program, the following package needs to be installed:
- pygame = ver. 2.6.1

Python used to code this program is ver. 3.13.7. 

This program uses built in Python libraries of os, math, and random.

To run this code, VS Code must be installed and zip file opened as folder in workspace. 
Navigate to the "RUN_ME.py" file and click on "Run current file in interactive environment."

If you are listed as a collaborator, you should clone the repository instead of downloading a local copy.
To clone the repository, open a new window in VS Code and clone using HTTPS.

PROGRAM DETAILS

Code structure and organization was of IY's own design. VS Code autofill used to help fill in 
repetitive code. VS Code AI was used to assist with the design of the pulsing feature on the 
sprites and debug a few persistent bugs that IY could not figure out how to resolve after countless 
attempts.
